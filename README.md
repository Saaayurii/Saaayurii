## 🧑‍💻 About me

I started in 2021 as a frontend developer and grew into full-stack: today I build web platforms end to end — Next.js on the front, NestJS microservices behind it, PostgreSQL/Redis underneath, Docker around all of it. I also have a background in C++, C#, Python and Assembly, which helps me look at problems from more than one angle.

🏢 Since 2026 I work at the **Institute of Artificial Intelligence Problems** on intelligent systems: question-answering models, LLM assistants, energy analytics.

🎮 In my own time I make **[Ashes of Eden](https://github.com/Saaayurii/ashes-of-eden)** — an open-source pixel action roguelite in Godot.

🎓 IT student at Donetsk State University (since 2022), now in the master's programme.

📫 Open to collaboration, freelance and interesting projects.
